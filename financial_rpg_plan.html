PROJECT CONCEPT / 像素 RPG 化财报研究

把读财报做成可升级、可打卡、可通关的研究旅程

目标不是把行业粗暴分类，而是把产业研究拆成一张张地图、一个个副本和一组组小任务。 用户每天推进一点，逐步从“看懂一家公司”升级到“理解一条产业链”，最后沉淀自己的投资灵感库。

世界地图：行业是场景，不是目录

地图承载研究场景。每个产业地图都有自己的关键问题、财报线索和高频观察点， 用户进入地图后再通过任务卡推进，而不是只按行业列表翻报告。

动力电池峡谷

围绕动力电池企业，追踪出货、价格、毛利率和现金流质量。

整车竞技场

比较比亚迪、赛力斯、长城汽车，拆销量、ASP、单车利润和渠道效率。

半导体矿洞

观察设备、材料、设计公司的库存周期、订单能见度和国产替代节奏。

光伏沙海

从价格、开工率、减值和现金流入手，识别周期底部和真实出清。

机器人城邦

把零部件、整机、应用场景拆成任务链，追踪商业化里程碑。

主线战役：从看一家公司到理解产业链

主线不追求一次读完全部财报，而是把复杂研究拆成七个连续关卡。前期先记录第一印象， 中段用财报证据验证和修正，最终沉淀前再确认公司画像。

第 1 章

初始印象

先写下对公司业务、客户和产业位置的第一判断，作为后续验证对象。

第 2 章

收入结构

拆产品、区域、客户和量价变化，找到增长来自哪里。

第 3 章

利润质量

看毛利率、费用率、扣非利润和非经常性损益的真实贡献。

第 4 章

现金与资产

用经营现金流、应收、存货和合同负债判断增长含金量。

第 5 章

产业对比

放到同产业头部公司里比较，识别强弱、周期和分化。

第 6 章

画像确认

回到第一印象，依据财报证据修正公司到底靠什么赚钱。

第 7 章

灵感沉淀

把结论、反证信号和后续跟踪动作写入个人研究日志。

章节达成机制：目标不是看完，而是产出可检查的研究件

每一章都由“章节目标、最小任务、可见产物、解锁条件”承接。用户不需要在本方案页输入内容； 最终产品里，每张任务卡会对应一个可打卡产物，完成后再推进下一章。

1. 初始印象卡

读公司简介和摘要，留下待验证判断：卖什么、卖给谁、为什么可能变化。

2. 财报证据卡

收入、利润、现金流每章至少完成一张证据卡，明确支持或推翻什么判断。

3. 产业参照卡

进入分支地图后，用同产业头部公司做横向参照，识别强弱和周期位置。

4. 画像确认卡

最终沉淀前先修正公司画像，再把可靠结论、反证信号和下次跟踪动作归档。

每日副本：每次只推进一个小胜利

点击任务卡即可打卡。这里不要求用户输入内容，重点是让研究动作变得明确、轻量、有反馈。

每日副本 0120 XP

读一页管理层讨论

只找管理层对收入、价格、需求、产能或客户结构的解释。

每日副本 0220 XP

找一个利润变化原因

判断利润变化来自收入、毛利率、费用、减值还是非经常性项目。

每日副本 0320 XP

核对现金流含金量

比较经营现金流与归母净利润，找是否存在利润好但现金弱。

每日副本 0420 XP

对比一个产业同伴

把同产业另一家公司加入对照，观察收入增速、毛利率和库存差异。

每日副本 0520 XP

记录一个反证信号

主动寻找可能推翻结论的信号：价格下行、应收走高、订单变弱。

每日副本 0620 XP

沉淀一个投资灵感

把今天最值得跟踪的业务变化，归档成后续可复盘的研究线索。

任务模板入口：公司初读副本

每日副本的最小闭环

实际产品只记录研究动作和进度，不内置公司数据。每次阅读都围绕一个最小问题展开， 完成后获得经验、徽章和下一关解锁反馈。

世界副本：国家价值链坐标

完成 4 个 Boss 关卡后解锁。用户需要研究该产业在国家价值链中的位置： 是基础能力、关键卡点、全球竞争优势，还是下游应用扩散节点。

地图卡池：先选场景，再进入副本

卡池用于选择阅读场景。第一版不内置公司数据，只提供可复用的研究地图； 用户可以把任意目标公司放入地图中，按同一套 RPG 任务推进。

成就墙：让阅读进度被看见

徽章不代表投资结论正确，只代表用户完成了结构化研究动作。这样能把“读财报”从一次性苦活， 变成持续可推进的学习系统。
